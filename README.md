# GfredMaster

Page d'accueil de mes web apps : https://gfred70.github.io/

Installée à la racine du site (dépôt `Gfred70.github.io`) : les applis s'ouvrent
dans la fenêtre de GfredMaster, sans barre d'adresse. Installer seulement GfredMaster
sur le téléphone.

- GfredAnalyzer : https://gfred70.github.io/GfredAnalyzer-app/
- GfredDream : https://gfred70.github.io/gfreddream-app/
- Gonflage O2 : https://gfred70.github.io/Prix-gonflage-O2/
- GfredO2Tank : bientôt (https://gfred70.github.io/GfredO2Tank/)

Ajouter une appli : une ligne dans `APPS` (index.html) + son icône dans `apps/`,
puis l'ajouter à `PRECACHE_URLS` et changer `CACHE_NAME` dans `sw.js`.
